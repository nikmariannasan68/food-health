# Food & Health — Узнай, что ты ешь

> «Твой выбор сегодня — твоё здоровье завтра»

Интерактивная образовательная платформа о том, как продукты и напитки влияют на организм, какие риски связаны с пищевыми привычками и что помогает профилактике. Интерфейс на русском языке.

**Статус:** первый релиз. Полностью готов сценарий для шести продуктов: сладкой газировки, чипсов, кофе, энергетиков, шоколада и лапши быстрого приготовления. Также есть 6 материалов о заболеваниях, 5 тестов, 7 карточек «Миф или факт», интерактивная анатомия на 10 органов и систем, профилактика, план привычек, сравнение, избранное, прогресс и поиск.

## Быстрый старт

```bash
npm install
npm run dev          # http://localhost:3000
```

Продакшен-сборка:

```bash
npm run build && npm run start
```

Требуется Node.js 20 или новее.

## Проверки

| Команда | Что проверяет |
|---|---|
| `npm test` | 15 unit-тестов: Zod-валидация всех данных, целостность связей (источники, заболевания, тесты), честная разметка состава, поиск, подсчёт результатов тестов, форматирование |
| `npm run test:e2e` | 11 браузерных тестов Playwright против `next start`: полный сценарий из ТЗ, фильтры, поиск, клавиатурная анатомия, сохранение прогресса, тема, 404, базовая доступность, ширина 320 px |
| `PREVIEW=1 npx playwright test` | Те же браузерные тесты против превью-сборки (без сервера) |
| `npm run typecheck` | TypeScript в строгом режиме |
| `npm run preview:build` | Собирает самодостаточный `preview/dist/index.html` из тех же компонентов (hash-маршруты) |

Перед первым запуском E2E установите браузер: `npx playwright install chromium`.

## Публикация на Vercel

1. Загрузите репозиторий на GitHub и импортируйте его в Vercel. Фреймворк Next.js определится автоматически.
2. Добавьте переменную окружения `NEXT_PUBLIC_SITE_URL=https://ваш-домен`. Она нужна для sitemap, canonical-ссылок и Open Graph.
3. Все страницы продуктов, заболеваний и тестов генерируются статически (`generateStaticParams`).

### Как добавить продукт

1. Добавьте объект в `src/content/products.ts`. Схема подскажет обязательные поля.
2. Для каждого значения состава укажите `status`:
   - `sourced` — число из конкретного источника;
   - `approximate` — ориентировочный диапазон;
   - `unknown` — на сайте будет «Данные уточняются».
3. Для каждой связи с органом укажите `evidence`:
   - `direct` — прямой эффект;
   - `causal` — доказанная причинная связь;
   - `association` — статистическая связь;
   - `diet-pattern` — влияние рациона в целом.
   Также укажите `confidence` и минимум один источник.
4. Добавьте иллюстрацию в `ProductArt.tsx` или используйте `art: "generic"`.
5. Запустите `npm test`: тесты не пропустят ссылки на несуществующие источники, заболевания или тесты.

Для перехода на базу данных (PostgreSQL + Prisma) замените реализацию `src/content/index.ts`. Компоненты получают данные только через этот слой.

## Научная достоверность

- Источники: ВОЗ, EFSA, CDC, FDA, USDA (систематический обзор DGAC 2025, FoodData Central), метаанализ в Sleep Medicine Reviews (2023). Полный список с датами — на странице `/sources`.
- Значения состава газировки и чипсов — ориентировочные диапазоны для категории, а не данные конкретной марки. Содержание кофеина в кофе и коле взято из источников (EFSA, FDA).
- **Все материалы помечены как ожидающие проверки медицинским редактором.** Источники сверены 22.11.2026, но рецензию квалифицированного врача или нутрициолога нужно провести до публичного запуска.

## Что отличается от исходного ТЗ и почему

- **Иконки, анимации, диаграммы.** Используются собственные лёгкие компоненты на SVG и CSS вместо `lucide-react`, `framer-motion` и `recharts`. Так меньше зависимостей и меньше размер бандла. Все анимации отключаются системной настройкой «уменьшить движение» или переключателем в подвале сайта. Имена иконок близки к Lucide, поэтому их легко заменить.
- **shadcn/ui не подключён.** Дизайн-система описана в `app/globals.css`: токены, светлая и тёмная темы, компоненты `.card`, `.btn`, `.chip`.
- **Изображения продуктов — векторные иллюстрации**, нарисованные для проекта. Случайных стоковых фото нет. Фотографии можно подключить через `next/image`.
- **Каталог пока из шести продуктов.** ТЗ требует 15 продуктов и 8 материалов о заболеваниях. Следующие продукты стоит добавлять только после сверки данных.
